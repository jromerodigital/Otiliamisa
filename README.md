# Misa de Honras - Otilia Inga Cueva (1 Mes)

Invitación digital interactiva y memorial en conmemoración al primer mes del sensible fallecimiento de nuestra amada **Otilia Inga Cueva** (19 de Setiembre de 2026).

---

## ✨ Características del Proyecto

- **Carta Ceremonial 3D Interactiva**: Sobre ceremonial borgoña con apertura interactiva y sello de lacre dorado.
- **Video y Atmósfera Celestial**: Video de fondo cinematográfico (`Otilia Fondo.mp4`) con máscara de luminosidad y lluvia de pétalos celestiales.
- **Música de Fondo Conmemorativa**: *Historia de un Amor - Los Panchos* integrada en un reproductor de audio interactivo.
- **Contador Regresivo en Tiempo Real**: Cuenta regresiva hacia el 19 de Setiembre de 2026 a las 6:00 PM.
- **Álbum y Galería de Recuerdos**: Lightbox interactivo en pantalla completa con 9 fotografías familiares.
- **Confirmación de Asistencia por WhatsApp**: Formulario modal que genera el mensaje personalizado directo a WhatsApp.
- **Ubicación en Google Maps**: Enlace directo a la Capilla en Jr. Abtao 1200, La Victoria.

---

## 🚀 Instalación y Ejecución Local

Para ejecutar el proyecto en tu entorno local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/jromerodigital/Otiliamisa.git
   cd Otiliamisa
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
